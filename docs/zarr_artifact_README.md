# BioModels multi-simulator comparison — zarr artifact

A single zarr store holding the batch-comparison run in the hierarchy:

```
root/                                     # .attrs: engines, biomodels, schema, generated_utc, source
  <BIOMD id>/                             # .attrs: comparisons (per sedml_job nRMSE matrix, buckets,
    <simulator>/                          #          closeness), runs (per-engine status/runtime)
      <sedml_job_id>/                     # an xarray group
        value  (time|scan, observable)    # float32; steady-state leaves are (observable,)
        coords: time|scan, observable
        .attrs: simulator, kind, is_reference, sedml_job, status, runtime_s, n_points
```

- **Simulators** include the live engines (`copasi`, `tellurium`, `simbio`,
  `amici`, `pysces`) and the BioSimulators reference engines, folded in as
  `reference_<engine>` (e.g. `reference_vcell`, `reference_copasi`). The `:` in
  the original `reference:<engine>` name is sanitized to `_` so the store is
  portable; the original name is in each leaf's `simulator` attr.
- **`kind`** per leaf is `utc` (time course), `repeated_task` (a 1-D parameter
  scan; axis coordinate is `scan`), or `steady_state` (no axis; one value per
  observable).

## Loading

```python
import xarray as xr, zarr

STORE = "compare_all_1054.zarr"

# Root metadata + per-model comparison scores
root = zarr.open_group(STORE, mode="r")
print(root.attrs["engines"], "|", root.attrs["n_biomodels"], "models")
comp = root["BIOMD0000000012"].attrs["comparisons"]   # {sedml_job: {matrix, bucket, ...}}

# One (biomodel, simulator, sedml_job) leaf as an xarray Dataset
ds = xr.open_zarr(f"{STORE}/BIOMD0000000012/copasi/auto_ten_seconds", consolidated=True)
ds["value"].sel(observable="A")        # the trajectory of species "A"
ds.coords["time"]                       # the sample-time axis
```

## Provenance / caveats

- **Resolution:** the series are the two-tier storage form of the run —
  **downsampled (~200 points) and cast to float32**. This is the surviving form
  of the full 1054-model run, not raw ODE-solver resolution. See the root
  `resolution_note` attr.
- Empty/failed `(model, simulator, job)` runs have no group; per-engine run
  status is under each model group's `runs` attr.
- Generated by `pbg_biomodels.zarr_export` (`vivarium-collective/pbg-biomodels`).
  The same layout is produced live by the `ZarrExportStep` at the end of the
  `batch-compare-biomodels` composite (set its `zarr_out` parameter).
